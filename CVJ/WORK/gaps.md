# Gaps (values only from the sources; preliminary, updated after extraction)
- Powers ratio: no source in the zip mentions it (grep across all 7 = 0 hits). Not shown on slides. Listed as a gap and a suggested reference.
- Basion–dens / basion–axial intervals (Harris "rule of 12"): no hits apart from table false positives. Pending agent confirmation.
- EPOS posters: blocked by the network, so no poster images.
- Confirmed by the extraction agents: there is no Powers ratio, basion–dens interval (Harris), basion–axial interval or condyle–C1 interval in any source. The nearest is the AIIMS "basion odontoid index (Whooley)": 5 mm in adults, up to 10 mm in children (neutral position).
- No Ranawat, Redlund-Johnell or Clark station values for rheumatoid cranial settling; it is described qualitatively only (AIIMS, Smoker).
- No Rule of Spence (lateral mass overhang) value for Jefferson fracture. Chong shows lateral mass displacement qualitatively.
- No Goel classification text. The Chong Ch 14 two-group developmental BI description is used instead.
- Levine–Edwards is absent. Hangman's fracture uses Effendi types (Chen).
- No tuberculosis image in any source. TB is covered as text plus Chen Table 5 (TB vs RA) and the AIIMS stages.
- Crowned dens: the term is absent. CPPD is described as retro-odontoid calcification and soft tissue (AIIMS, Chen).
