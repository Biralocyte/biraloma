# Candidate references from the Teegala reference list (numbers as printed)

1. Ref 5: Behari S, Nayak SR, Bhargava V, Banerji D, Chhabra DK, Jain VK. Craniocervical tuberculosis: Protocol of surgical management. Neurosurgery 52:72-81, 2003. Why: the competing disability-grade-based surgical protocol the Teegala scheme is set against (alternative decision points).
2. Ref 15: Gupta SK, Mohindra S, Sharma BS, et al. Tuberculosis of the craniovertebral junction: Is surgery necessary? Neurosurgery 58:1144-1150, 2006. Why: 56 patients managed conservatively, with some needing surgery for residual reducible AAD; supports the "conservative first" message.
3. Ref 24: Lifeso R. Atlanto-axial tuberculosis in adults. J Bone Joint Surg Br 69B:183-187, 1987. Why: earliest radiological grading of CVJ TB (stated in the text to grade severity but not guide treatment), useful as historical classification context.
